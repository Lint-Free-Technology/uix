# Home Summary Spark

The `home-summary` Spark filters the entities considered by one native Home Assistant `home-summary` card. It is useful when an integration's entities should not contribute to Maintenance, Lights, Security, Media Players, or other Home Overview summary counts.

It is a Card Forge Spark, not a strategy Spark. Wrap a card generated by a strategy with [Configuration Spark `wrap_card`](config.md#wrap-generated-cards), or use it directly when you Forge a Home Summary card yourself.

```yaml
type: custom:uix-forge
forge:
  mold: card
  sparks:
    - type: entities
      id: excluded_from_maintenance
      filter:
        include:
          - label: excluded_from_maintenance
    - type: home-summary
      exclude:
        - $in_entities: excluded_from_maintenance
element:
  type: home-summary
  summary: maintenance
```

The example hides every entity carrying the Home Assistant label `excluded_from_maintenance` from the card's Maintenance calculation. Use Home Assistant's label spelling exactly; labels use snake case.

## Spark options

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `type` | string | — | Required. Must be `home-summary`. |
| `include` | list of filters or `$in_entities` references | all entities | Starts this card's local entity universe with the union of its matching IDs. When present, even an empty list means no entities are included. |
| `exclude` | list of filters or `$in_entities` references | `[]` | Subtracts matching IDs from this card's local Home Assistant context after `include` is applied. |

Only one Home Summary Spark can be used by a Forge, and the resolved card must be `type: home-summary`.

## Filters

Each ordinary `include` or `exclude` entry has the same familiar shape as an [Entities Spark filter](entities.md#filters). Entries within one option are combined as an OR. If `include` is omitted, the card starts with every currently available entity; when it is present, only its matching entities are considered. UIX then subtracts all `exclude` matches. The supported filter keys are `domain`, `entity_id`, `name`, `group`, `area`, `floor`, `device`, `label`, `integration`, `entity_category`, `state`, `attributes`, `and`, `or`, and `not`.

```yaml
exclude:
  - domain: browser_mod
  - label: excluded_from_maintenance
  - and:
      - domain: sensor
      - attributes:
          device_class: battery
```

Use `{ $in_entities: name }` to reuse a named query-only Entities Spark in the same Forge. This is particularly useful when the same exclusion must drive both a Home Summary card and a Configuration Spark. A [Foundry](../foundries.md) can hold the query once; every Forge that uses it still evaluates the selection locally against its own Home Assistant context.

```yaml
forge:
  sparks:
    - type: entities
      id: excluded_from_maintenance
      filter:
        include:
          - label: excluded_from_maintenance
    - type: home-summary
      exclude:
        - $in_entities: excluded_from_maintenance
```

The Spark supplies a filtered `states` and entity-registry projection to this wrapped card only. It does not alter Home Assistant's shared registries, other cards, the summary card's navigation destination, or broad service targets such as `area_id` actions. To replace the native Maintenance destination as well, see the complete [Home dashboard Maintenance example](config.md#wrap-generated-cards).

## Updates

The native Home Summary card continues to update normally for retained entities. UIX recalculates inline selectors and referenced query-only results with a 500 ms trailing debounce when a filter-relevant state or registry value changes, matching the behaviour of the Entities Spark. When those local query results are used only by this Spark, it updates the wrapper's local context without recreating the native summary card; if the same result is also used by a Configuration Spark or an element template, Forge takes its normal refresh path so that other consumer remains current.
