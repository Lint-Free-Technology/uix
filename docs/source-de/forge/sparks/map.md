# Map Spark

Der Map Spark hilft, Zoom und Mittelpunkt einer Kartenansicht bei Home-Assistant-Aktualisierungen beizubehalten.

## Einsatz

Home-Assistant-Karten aktualisieren sich regelmäßig. Bei Kartenansichten kann dadurch Zoom oder Position zurückspringen. Der Map Spark stabilisiert diese Ansicht.

## Hinweise

- Besonders hilfreich bei Tracking- oder Tour-Dashboards.
- Prüfe Karten mit mehreren Entitäten.
- Setze ihn nur dort ein, wo Nutzer die Karte interaktiv verschieben oder zoomen.
