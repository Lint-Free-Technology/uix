# More-info Spark

Der More-info Spark bindet Home-Assistant-More-info-Inhalte für eine Entität in ein Forge-Element ein.

## Einsatz

Der Spark ist nützlich, wenn Details zu einer Entität direkt in einer eigenen Karte sichtbar sein sollen, statt nur per Dialog.

## Hinweise

- More-info-Inhalte können je nach Entität unterschiedlich groß sein.
- Plane genug Platz im Layout ein.
- Bei kleinen Karten ist ein Button zum Öffnen des More-info-Dialogs oft übersichtlicher.
