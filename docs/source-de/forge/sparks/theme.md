# Theme Spark

Der Theme Spark wendet ein Home-Assistant-Frontend-Theme auf ein Forge-Element oder ein darin gefundenes Element an.

## Beispielidee

```yaml
forge:
  sparks:
    - type: theme
      theme: Wohnzimmer
```

## Hinweise

- Gut für Karten, die bewusst anders aussehen sollen als die aktuelle View.
- Theme-Werte können mit lokalen UIX-Styles kombiniert werden.
- Dark-Mode-Verhalten immer mitprüfen.
