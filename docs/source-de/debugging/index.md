# Debugging

Wenn UIX-Konfiguration nicht wie erwartet wirkt, helfen diese Bereiche:

- [Karten debuggen](./cards.md)
- [Templates debuggen](./templates.md)
- [Cache-Probleme beheben](./cache.md)

Typische Ursachen sind Browsercache, nicht neu geladene Frontend-Ressourcen, falsche Selektoren oder Home-Assistant-Elemente, die erst verzögert gerendert werden.
