# UI eXtension für Home Assistant

![UIX Logo](./assets/images/mixed.png)

## Was ist UI eXtension?

!!! note inline end "Für Card-mod-Nutzer"
    Wenn du von Card-mod wechselst, lies zuerst die [FAQ](./faq.md). Dort sind die wichtigsten Unterschiede, Migrationspunkte und typischen Stolperstellen zusammengefasst.

UI eXtension, kurz UIX, ist eine Home-Assistant-Integration für Anpassungen an der Oberfläche. Sie erweitert Karten, Zeilen, Badges, Dialoge und andere Frontend-Elemente mit CSS, Templates und zusätzlichen UI-Verhalten.

UIX besteht aus zwei großen Bereichen:

- [UIX Styling](./using/index.md) für CSS-Anpassungen an Home-Assistant-Frontend-Elementen.
- [UIX Forge](./forge/index.md) für dynamisch erzeugte Elemente, wiederverwendbare Vorlagen und erweiterte Sparks.
