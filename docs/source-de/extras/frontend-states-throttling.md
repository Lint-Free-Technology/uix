# Frontend State Throttling

Frontend State Throttling kann Aktualisierungen begrenzen, damit komplexe Dashboards flüssiger reagieren.

## Wann sinnvoll?

Diese Option ist hilfreich, wenn viele Entitäten häufig aktualisiert werden und dadurch Styling oder Templates sehr oft neu berechnet werden.

## Hinweise

- Nicht für jede Karte aktivieren, sondern gezielt bei spürbaren Performance-Problemen.
- Nach Aktivierung prüfen, ob Zustände noch schnell genug sichtbar werden.
- Besonders bei Wanddisplays und älteren Tablets kann die Option helfen.
