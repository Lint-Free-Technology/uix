# UIX Actions

UIX Actions erweitern Home-Assistant-Aktionen um zusätzliche Möglichkeiten im UIX-Kontext.

## Einsatz

Sie eignen sich, wenn eine normale Home-Assistant-Aktion nicht genug Kontext hat oder wenn UIX-interne Zustände einbezogen werden sollen.

## Hinweise

- Aktionen sollten klar benannt werden.
- Kritische Aktionen sollten mit Bestätigung oder Lock Spark geschützt werden.
- Bei mehreren Aktionen empfiehlt sich eine kleine Testkarte.
