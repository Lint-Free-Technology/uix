# Entwickler

Dieser Bereich richtet sich an Entwickler, die UIX erweitern oder eigene Karten und Themes mit UIX kompatibel machen möchten.

- [Karten entwickeln](./cards.md)
- [Themes entwickeln](./themes.md)

Wichtig ist vor allem, DOM-Strukturen stabil und nachvollziehbar zu halten, damit UIX gezielt Elemente finden und verändern kann.
